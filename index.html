Deriv API Connection

How to connect with Deriv API

  1. Log in to your Deriv account.
  2. Open Account settings. On desktop, click the profile icon near the notification bell. On mobile, open the side menu, then Account settings.
  3. Go to Security and safety, then API token.
  4. Select Read and Trade only. Do not select Payments or Admin.
  5. Enter a token name, for example "myname", then click Create.
  6. Copy the generated token.
  7. Paste it below, then click Save & connect.
